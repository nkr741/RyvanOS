## Feature Lifecycle

Every feature follows this lifecycle — no shortcuts:

```
Business Idea → Product Spec → Architecture Review → UX Design
→ API Design → Database Design → Implementation → Testing
→ Security Review → Performance Review → Documentation → Merge
```

Use prompts: `planning.md` → `implementation.md` → `review.md`

## Founder Mode

Before building anything, ask: **"Would this reduce founder work?"**

If no — don't build it.
